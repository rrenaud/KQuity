How this works

We trained an AI model on a large set of quality-filtered Killer Queen games to predict each team's chance of winning at any moment during a match, based on 52 different in-game factors.

To understand how much worker composition alone matters, we isolated its effect by averaging out everything else—berries, snail position, maiden control, queen lives—across 2,059,168 game-state observations. (Technical detail, safe to skip: we fit logit(P) ≈ f(blue_workers) − f(gold_workers) via OLS on the model's logit predictions, giving each worker state a single scalar value.) The baseline is a team of 4 drones, which is set to exactly 50% (no advantage). The Win% column shows how much better or worse a given worker lineup is compared to that baseline, assuming everything else is equal.

Hover over a worker icon to see how much the win probability changes when that worker dies or gets upgraded.
